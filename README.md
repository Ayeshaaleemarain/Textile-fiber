# Textile Fiber & Process Guide

A Streamlit web application for textile engineering students.

## Features

- Fiber Library
- Textile Manufacturing Processes
- Fiber Comparison
- Knowledge Quiz
- Textile Glossary
- CSV Download

## Technologies

- Python
- Streamlit
- Pandas

## Installation

Install the required libraries:

    pip install -r requirements.txt

Run the application:

    streamlit run app.py

## Deployment

1. Upload all three files to a GitHub repository.
2. Open https://share.streamlit.io/
3. Connect your GitHub account.
4. Select your repository.
5. Set the main file path to app.py.
6. Click Deploy.

## Purpose

This application provides introductory educational
information about textile fibers and manufacturing processes.

Actual manufacturing routes vary according to fiber type,
yarn system, machinery, and fabric construction.
